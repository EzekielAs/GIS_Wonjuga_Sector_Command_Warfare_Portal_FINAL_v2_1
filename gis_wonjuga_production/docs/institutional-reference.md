# Institutional reference

The portal uses the requested institutional name:

**GHANA IMMIGRATION SERVICE WONJUGA SECTOR COMMAND WARFARE**

The official Ghana Immigration Service website currently lists **WONJUGA SECTOR COMMAND** under the North East Region.

Official website: https://gis.gov.gh/
North East Region: https://gis.gov.gh/north-east-region/

The official GIS Strategic Plan identifies the Service motto as **Friendship with vigilance** and the official emblem is shown in GIS publications. The application therefore uses the motto in the interface but does not ship a fabricated crest. Insert the approved official logo asset supplied by the command before public release.
